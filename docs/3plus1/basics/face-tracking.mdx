# フェイストラッキング

FT拡張をインストールすると、実際の顔の動きに、スティックによる表情ニュアンスと、ジェスチャーによる目の記号・演出を重ねられます。インストール手順は [FT拡張のインストール](/3plus1/getting-started/ft-install) を参照してください。

---

### 発話中の口

通常の発話では、VRChat 標準のリップシンクが優先されます。口のトラッキングが有効な間、どちらかの手で**ポイント**をすると、発話中も FT の口を優先できます。ポイントを解除すると元に戻ります。この機能は Modifier が OFF でも使えます。

## スティックの配置

倒した方向でニュアンスを選び、倒す量で強さを調整します。中央はニュートラルです。

<DirectionPad
  up={{icon:'CONFUSE', label:'上：CONFUSE', desc:'困惑'}}
  left={{icon:'ANGER', label:'左：ANGER', desc:'怒り'}}
  center={{label:'中央', desc:'ニュートラル'}}
  right={{icon:'PLEASURE', label:'右：PLEASURE', desc:'楽しい・嬉しい'}}
  down={{icon:'SORROW', label:'下：SORROW', desc:'悲しい'}}
/>

スティック単独では眉のニュアンスが動きます。目の記号は、次の「Modifier ON の演出」で重ねて表示します。記号を出すときは、斜めではなく目的の方向へはっきり倒してください。

:::warning[スティックのリセット]

中央へ戻すには、スティックのカーソルを中央へ動かしてください。メニューを閉じただけでは戻らないことがあります。

:::

## うまく動かないとき

| 症状 | 確認すること |
|------|------------|
| FT 全体が動かない | VRCFaceTracking の受信、モジュール、VRChat の OSC、AUTO を順に確認 |
| 記号だけ出ない | Modifier が ON か、VRChat が正しくジェスチャーを認識しているか確認 |
| ハートや星が出ない | ニュアンスの制限を確認し、スティックを中央へ戻して試す |
| うるうる解除後にハイライト／瞳サイズが残る | 両目で一度瞬きする |
| 発話中だけ口が違う | 標準リップシンクが優先されています。FT の口を優先するにはポイント |
| 容量エラー | 追加アセットを含む最終構成のパラメーター使用量を確認（[パラメーター容量](/3plus1/ft-extension/)） |
