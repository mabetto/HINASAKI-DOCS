# SE拡張

## 概要

SE拡張（`SA_A2XL_R18.prefab`）は Modular Avatar で Non-Destructive に追加する R18 拡張パーツです。本体アバターに追加するだけで以下の機能が有効になります。

- 接触検出と、接触量に応じた変形（クリトリス・乳首）
- 放尿・射乳の液体エフェクトと効果音
- SPS による挿入深度の検出と変形

## 接触検出システム（ContactReceiver）

VRChat の ContactReceiver コンポーネントにより、他プレイヤーや自分のアバターからの接触を検出します。

| センサー | 検出部位 | 対応タグ | 検出半径 |
|---------|---------|---------|---------|
| Sen_Clit | クリトリス | Foot / Finger | 0.02m |
| L_Sen_Nipple | 左乳首 | Foot / Finger | 0.025m |
| R_Sen_Nipple | 右乳首 | Foot / Finger | 0.025m |

全センサー共通設定：
- `allowSelf: true` — 自分自身の接触も検出
- `allowOthers: true` — 他プレイヤーの接触も検出
- `minVelocity: 0.05` — 最低速度フィルター（誤検出防止）

### パラメーターの構造

接触検出システムは Bool と Float の2種類のパラメーターを組み合わせて動作します。

| パラメーター | 型 | 役割 |
|------------|---|------|
| `Clitoris_Contact` | Bool | 現在接触中かどうか（ContactReceiver が直接書き込む） |
| `Nipple_L_Contact` | Bool | 左乳首への接触中フラグ |
| `Nipple_R_Contact` | Bool | 右乳首への接触中フラグ |
| `Clitoris` | Float | クリトリスへの累積接触強度（0.0〜1.0） |
| `Nipple_L` | Float | 左乳首への累積接触強度（0.0〜1.0） |
| `Nipple_R` | Float | 右乳首への累積接触強度（0.0〜1.0） |

`_Contact` 系の Bool はリアルタイムな「今触れているか」を表し、Float 系は接触履歴の累積値として蓄積されます。Float パラメーターは `synced: true / saved: false` — セッション中のみ同期され、ログアウトでリセットされます。

### 値の増減ロジック

接触中（`_Contact = true`）は対応する Float 値が **+0.02/tick** で上昇します。接触が離れると `SYS_NSFW_Contact_Subtract` レイヤーが起動し、値が 0.2 以上ある限り **-0.02/tick** で徐々に減衰させます。これにより接触の余韻が自然に残る挙動になっています。

Float 値が **0.99 を超える**と特殊ステートへ遷移し、液体エフェクトが始まります：

| 部位 | 条件 | 遷移先ステート | 内容 |
|------|------|-------------|------|
| クリトリス | `Clitoris > 0.99` かつ `CostumeBody = 2` | `CLITORIS_ORGASM` | 放尿（`Peeing_System` の `Emitter_Pee` を有効化） |
| 左乳首 | `Nipple_L > 0.99` かつ `CostumeBody` が 0・1 以外 | `LACTATION_L` | 射乳（左の Milk エミッターを有効化し、`act_lactation_L` を 100 に） |
| 右乳首 | `Nipple_R > 0.99` かつ `CostumeBody` が 0・1 以外 | `LACTATION_R` | 射乳（右の Milk エミッターを有効化し、`act_lactation_R` を 100 に） |

`CostumeBody` が 1 になるか、再生が終わると `WAIT_RESET` ステートへ移り、値が 0.99 以下に下がるまで再発動しません。

### アニメーターレイヤー構成

R18FX Controller は役割ごとに独立したレイヤーで構成されています。

| レイヤー | 役割 |
|---------|------|
| `FX_PUBICHAIR` | `PubicHair` で陰毛の表示・非表示を切り替え |
| `SYS_NSFW_Contact_Subtract` | 接触が離れたとき Float 値を自動減衰させるシステム |
| `FX_CLITORIS_CONTACT` | クリトリス接触中に `Clitoris` を加算し、上限でオーガズム（放尿）へ遷移 |
| `FX_NIPPLE_L_CONTACT` | 左乳首接触中に `Nipple_L` を加算し、上限で射乳へ遷移 |
| `FX_NIPPLE_R_CONTACT` | 右乳首接触中に `Nipple_R` を加算し、上限で射乳へ遷移 |
| `FX_CLITORIS_ERECTION` | `Clitoris` 値で Clit ボーンの LocalScale をドライブ |
| `FX_NIPPLE_L_ERECTION` | `Nipple_L` 値で Nipple.L ボーンの LocalPosition をドライブ |
| `FX_NIPPLE_R_ERECTION` | `Nipple_R` 値で Nipple.R ボーンの LocalPosition をドライブ |
| `FX_PUSSY_OPEN` | `Pussy_Open` で `Basebody` のシェイプキー `act_(i)_open` をドライブ |
| `CFG_LIQUID_BRIGHTNESS` / `CFG_LIQUID_MONOCHROME_LIGHTING` | 液体の明るさ・ライトのモノクロ化を、本体の `Brightness` / `Lighting(mono)` に連動 |
| `SFX_*` | 液体の効果音の再生制御（[液体エフェクトと効果音](#液体エフェクトと効果音)） |

:::warning[改変時の注意]

`FX_PUSSY_OPEN`・`FX_CLITORIS_CONTACT`・`FX_NIPPLE_*_CONTACT` の遷移には `CostumeBody` の条件が含まれます。デフォルト衣装を削除した場合は `CostumeBody = 2`（脱衣状態）にならず、くぱぁ・放尿・射乳が機能しません。

**対処法：**
- `SA_A2XL_SE R18FX` の `CostumeBody` パラメーターを削除し、各レイヤーの `CostumeBody` の条件も削除する
- または、独自衣装の脱衣ステートに `CostumeBody = 2` を割り当てる

:::

### アニメーションのドライブ方法

ERECTION 系レイヤーは `m_TimeParameterActive: true` を使い、アニメーションの再生位置（Time）を Float パラメーターの値で直接制御します。これにより「値 0.0 = 通常形状 / 値 1.0 = 最大変形」が Float 値に比例してリアルタイムに反映されます。

| アニメーション | 制御対象 | 手法 |
|--------------|---------|------|
| CLITORIS_ERECTION | `Armature/Hips/Clit` | ボーンの LocalScale を変化 |
| NIPPLE_L_ERECTION | `Armature/.../Nipple.L` | ボーンの LocalPosition を変化 |
| NIPPLE_R_ERECTION | `Armature/.../Nipple.R` | ボーンの LocalPosition を変化 |
| PUSSY_OPEN | `Basebody` | シェイプキー `act_(i)_open` を 0〜100 で変化 |
| CLITORIS_ORGASM | `Peeing_System/Urethra/Emitter_Pee` | `IsActive` を ON（`_OFF` で OFF） |
| LACTATION_L_ON / LACTATION_R_ON | `Lactation_System` の Milk エミッター、`Basebody` | エミッターの `IsActive` を ON、`act_lactation_L/R` を 100、`_DropAlpha` を約1.5秒で 0→1 |

## 液体エフェクトと効果音

放尿（`Peeing_System`）と射乳（`Lactation_System`）は、粒子と効果音で構成されています。

| システム | 粒子 | 発動 |
|---------|------|------|
| `Peeing_System` | 流れ（Pee）、滴（Pee_drop）、水たまり（Pee_revert 系） | `CLITORIS_ORGASM` |
| `Lactation_System` | 左右それぞれ Milk（流れ）、WaterRunoff（伝い落ちる液）、AccentDrops（滴） | `LACTATION_L` / `LACTATION_R` |

### 液体の明るさ

液体のマテリアルは、本体のプリファレンスメニューの設定に連動します。

| パラメーター | 液体のプロパティ | 範囲（0 → 1） |
|------------|----------------|--------------|
| `Brightness` | `_LightMinLimit` | 0.05 → 1.0 |
| `Lighting(mono)` | `_MonochromeLighting` | 0.0 → 1.0 |

### 効果音

| 効果音 | ファイル | 設定 |
|--------|---------|------|
| 放尿の流れ（`Flow`） | `SA_A2XL_R18_LEAK_A.wav` | 音量 0.5 / 最大距離 2m |
| 射乳の流れ（`Flow`） | `SA_A2XL_R18_LEAK_B.wav` | 音量 0.5 / 最大距離 2m |
| 着弾音（`Impact`） | `SA_A2XL_R18_DROP.wav` | ループ / 音量 0.6 / 最大距離 4m |
| ランダム SE（`SFX_RANDOM`） | `SA_A2XL_R18_SPLURT_A〜E.wav` | 音量 0.5 / 最大距離 4m |

- **流れの音**：音源が液体の軌道（`Trajectory`）に沿って移動します。
- **着弾音**：液体の着弾点は8か所（`Hit_00`〜`Hit_07`）で判定し、当たっている位置の音源に重み（`Weight`）を切り替えます。音量は `*_ImpactLevel` に連動し、0.001 を超えている間ループ再生、0.0001 以下で停止します。
- **ランダム SE**：`SFX_CONTACT_A` / `SFX_CONTACT_B` が 0.75 を超えると、SPS の `Pussy` と `Anus` 配下の `SFX_RANDOM` を有効にして再生します。両方が 0.5 以下に戻るまで再発動しません。

`SFX_Pee_*` / `SFX_MilkL_*` / `SFX_MilkR_*` / `SFX_CONTACT_*` は、効果音の制御に使われるアニメーター内部のパラメーターです。

## SPS（VRCFury Sexual Penetration System）

VRCFury v1.1174.0 による侵入深度検出システムです。ContactReceiver とは独立して動作します。

| オブジェクト | SPS名称 | 対応 BlendShape |
|------------|---------|----------------|
| Pussy | おまんこ | act_(i)_push / open_half1 / open_half2 |
| Anus | あなる | act_*_push / open_half1 / open_half2 |

侵入深度に応じて BlendShape が自動的に駆動されます。`enableAuto: true` により自動検出が有効です。

ArmatureLink（`linkMode: 4`）によりベースアバターのボーン階層へ Non-Destructive に統合されます。

### SPS_DEFORM_FX

`SA_A2XL_SE SPS_DEFORM_FX` コントローラーは、SPS の侵入深度（`SPS_DEPTH`）と速度（`SPS_VELOCITY`）から、押し込み（PUSH）と引き抜き（SUCK）を判定して変形を切り替えます。

| ステート | 遷移条件 |
|---------|---------|
| `PUSH` | 深度の変化量が -0.00015 以下、`SPS_DEPTH` が 0.12 以下、`SPS_VELOCITY` が -0.005 以下 |
| `SUCK` | 深度の変化量が 0.00015 超、`SPS_DEPTH` が 0.12 以下、`SPS_VELOCITY` が 0.005 超 |
| `NEUTRAL` | `SPS_DEPTH` が 0.12 を超える。または `PUSH_SETTLE` / `SUCK_SETTLE`（変化量が ±0.00015 以内に収まった状態）を経由して復帰 |
