# FT Extension

The FT Extension (`SA_FaceTracking.prefab`) is placed directly under the avatar. For usage, see [Face Tracking](/3plus1/basics/face-tracking); for installation, see [Installing the FT Extension](/3plus1/getting-started/ft-install).

---

## Parameter Capacity

The FT Extension uses **9 synchronized bits**.

Continuous face inputs are synchronized by VRChat's native face tracking ([VRChat docs: networking and synced parameters](https://creators.vrchat.com/avatars/face-tracking/#networking-and-synced-parameters)). The precision of native face tracking synchronization varies with factors such as distance. Menu controls and the on/off state of some expressions are synchronized with custom parameters.

<WarningCard>
When adding clothing or other assets, check that the final Expression Parameters cost in the VRChat SDK is within 256 bits.
</WarningCard>
