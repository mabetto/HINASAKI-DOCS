# FT拡張

FT拡張（`SA_FaceTracking.prefab`）は、アバター直下に配置して使用します。操作方法は [フェイストラッキング](/3plus1/basics/face-tracking)、導入手順は [FT拡張のインストール](/3plus1/getting-started/ft-install) を参照してください。

---

## パラメーター容量

FT 単体の標準構成では、同期パラメーターを **253bit** 使用します。SE拡張やましゅまろPBとの併用時は、同期容量を自動で調整します。このとき他者へ送る一部の FT 入力の段階数が減るため、自分と他者で滑らかさが異なることがあります。

### 構成ごとの違い

SE拡張・ましゅまろPBのパラメーターが導入されているかを自動で判別し、構成に応じて同期から外します。自分の入力は変わらず、他者へ送る精度だけが下がります。

| 構成 | 同期から外れる量 | 他者へ送る FT 入力の変化 |
|------|------------------|--------------------------|
| FT 単体 | なし（253bit） | なし |
| FT ＋ SE拡張 | 33bit | 24 入力の精度を 1bit 下げる。うち 6 入力は最上位の 1bit のみ送る。設定値 3 つは送らない |
| FT ＋ SE拡張 ＋ ましゅまろPB | 38bit | 上記に加えて、5 入力が最上位の 1bit のみになる（計 11 入力） |
| FT ＋ ましゅまろPB（SE拡張なし） | 2bit | 2 入力（`NoseSneer`・`MouthPress`）の精度を 1bit 下げる |

対象の入力（パラメーター名）：

- 精度を 1bit 下げる（SE拡張導入時）：`BrowExpressionLeft` / `BrowExpressionRight` / `NoseSneer` / `CheekPuffLeft` / `JawForward` / `JawX` / `LipFunnel` / `LipPucker` / `LipSuckUpper` / `LipSuckLower` / `MouthLowerDown` / `MouthUpperUpRight` / `MouthUpperUpLeft` / `MouthRaiserUpper` / `MouthRaiserLower` / `MouthPress` / `MouthStretchLeft` / `MouthStretchRight` / `MouthX` / `SmileFrownLeft` / `SmileFrownRight` / `TongueOut` / `EyeSquintLeft` / `EyeSquintRight`
- 最上位の 1bit のみ送る（SE拡張導入時）：`CheekPuffLeft` / `JawForward` / `LipSuckUpper` / `LipSuckLower` / `MouthPress` / `EyeSquintRight`
- 最上位の 1bit のみ送る（さらにましゅまろPB併用時）：`NoseSneer` / `MouthUpperUpRight` / `MouthUpperUpLeft` / `MouthRaiserUpper` / `MouthRaiserLower`
- 送らない設定値（SE拡張導入時）：`FaceTrackingEmulation` / `FaceTrackingLimits` / `FT/EyeSync`

<WarningCard>
衣装や追加ギミックを増やす場合は、VRChat SDK で最終的な Expression Parameters 使用量が 256bit 以内か確認してください。FT 単体でも空きは少なく、自動調整は追加アセットの容量を確保しません。
</WarningCard>
