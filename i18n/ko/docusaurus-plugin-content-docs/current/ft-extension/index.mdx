# FT 확장

FT 확장（`SA_FaceTracking.prefab`）은 아바타 바로 아래에 배치하여 사용합니다. 조작 방법은 [페이스 트래킹](/3plus1/basics/face-tracking), 설치 절차는 [FT 확장 설치](/3plus1/getting-started/ft-install)를 참조하십시오.

---

## 파라미터 용량

FT 확장은 동기화 파라미터를 **9bit** 사용합니다.

얼굴의 연속적인 입력은 VRChat 표준 FT로 동기화합니다（[VRChat 공식：표준 FT의 동기화](https://creators.vrchat.com/avatars/face-tracking/#networking-and-synced-parameters)）. 표준 FT의 동기화 정밀도는 거리 등에 따라 달라집니다. 메뉴 조작과 일부 표정의 ON/OFF는 커스텀 파라미터로 동기화합니다.

<WarningCard>
의상이나 추가 에셋을 늘릴 때는 VRChat SDK에서 최종 구성의 Expression Parameters 사용량이 256bit 이내인지 확인하십시오.
</WarningCard>
