# FT拡張

FT拡張（`SA_FaceTracking.prefab`）は、アバター直下に配置して使用します。操作方法は [フェイストラッキング](/3plus1/basics/face-tracking)、導入手順は [FT拡張のインストール](/3plus1/getting-started/ft-install) を参照してください。

---

## パラメーター容量

FT拡張は、同期パラメーターを **9bit** 使用します。

顔の連続的な入力は、VRChat 標準 FT で同期します（[VRChat 公式：標準 FT の同期](https://creators.vrchat.com/avatars/face-tracking/#networking-and-synced-parameters)）。標準 FT の同期精度は、距離などによって変わります。メニュー操作や、一部の表情の ON/OFF は、カスタムのパラメーターで同期します。

<WarningCard>
衣装や追加アセットを増やす場合は、VRChat SDK で最終構成の Expression Parameters 使用量が 256bit 以内か確認してください。
</WarningCard>
