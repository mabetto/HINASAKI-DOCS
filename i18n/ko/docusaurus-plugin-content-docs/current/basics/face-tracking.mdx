# 페이스 트래킹

FT 확장을 설치하면 실제 얼굴의 움직임에 스틱으로 조절하는 표정 뉘앙스와 제스처로 표시하는 눈 기호·연출을 더할 수 있습니다. 설치 절차는 [FT 확장 설치](/3plus1/getting-started/ft-install)를 참조하십시오.

---

### 발화 중의 입

일반 발화에서는 VRChat 표준 립싱크가 우선입니다. 입 트래킹이 유효한 동안 어느 한 손으로 **Point**를 하면 발화 중에도 FT 입을 우선할 수 있습니다. Point를 풀면 원래대로 돌아갑니다. 이 기능은 Modifier가 OFF여도 사용할 수 있습니다.

## 스틱 배치

기울인 방향으로 뉘앙스를 선택하고 기울인 양으로 강도를 조절합니다. 중앙은 중립입니다.

<DirectionPad
  up={{icon:'CONFUSE', label:'위：CONFUSE', desc:'곤혹'}}
  left={{icon:'ANGER', label:'왼쪽：ANGER', desc:'분노'}}
  center={{label:'중앙', desc:'중립'}}
  right={{icon:'PLEASURE', label:'오른쪽：PLEASURE', desc:'즐거움·기쁨'}}
  down={{icon:'SORROW', label:'아래：SORROW', desc:'슬픔'}}
/>

스틱만 사용하면 눈썹 뉘앙스가 바뀝니다. 눈 기호는 아래 「Modifier ON의 연출」의 제스처로 더합니다. 기호를 표시할 때는 대각선이 아니라 원하는 방향으로 확실히 기울이십시오.

:::warning[스틱 초기화]

스틱의 커서를 중앙으로 움직여 되돌리십시오. 메뉴를 닫기만 하면 초기화되지 않을 수 있습니다.

:::

## Modifier ON의 연출

- 둘을 동시에 지정하면 하트가 우선입니다.
- 홍조는 하트 눈과 세트이며 단독으로는 표시할 수 없습니다.

## 제대로 동작하지 않을 때

| 증상 | 확인할 것 |
|------|----------|
| FT 전체가 동작하지 않음 | VRCFaceTracking 수신, 모듈, VRChat OSC, AUTO를 차례로 확인 |
| 기호만 나오지 않음 | Modifier가 ON인지, VRChat이 제스처를 올바르게 인식하는지 확인 |
| 하트나 별이 나오지 않음 | 뉘앙스 제한을 확인하고 스틱을 중앙으로 되돌려 시도 |
| 촉촉한 눈 해제 후 하이라이트／동공 크기가 남음 | 양쪽 눈을 한 번 깜빡임 |
| 발화할 때만 입이 다름 | 표준 립싱크가 우선입니다. FT 입을 우선하려면 Point 사용 |
| 용량 오류 | 추가 에셋을 포함한 최종 구성의 파라미터 사용량 확인（[파라미터 용량](/3plus1/ft-extension/)） |
